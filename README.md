   * Compares scaling-invariant EAR and MAR ratios to sound instant fatigue alert alarms.
   * [Live Web App](https://driverdrowsinessdetection06.streamlit.app/) | [GitHub Repository](https://github.com/myladivyasaisri/driver_drowsiness_detection)

2. **AI Resume Analyzer**
   * Automated ATS evaluation pipeline checking candidate skills against industry metrics.
   * Outputs targeted skill-gap graphs and downloadable alignment reports.
   * [Live Web App](https://myladivyasaisri.github.io/Ai-resume-analyzer/) | [GitHub Repository](https://github.com/myladivyasaisri/Ai-resume-analyzer)
